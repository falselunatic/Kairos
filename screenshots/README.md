Drop screenshot images here, then reference them from the main `README.md` using:

```markdown
![Chat](screenshots/chat.png)
```

Suggested filenames (matching the Features table in the main README):

- `chat.png` - the main Chat page
- `code.png` - Kairos Code
- `docs.png` - Docs Q&A
- `notes.png` - Notes
- `memories.png` - Memories
- `roast.png` - Roast Battle
- `about.png` - About page
- `extension.png` - the Chrome extension popup

PNG or JPG both work. Keep each under a few hundred KB so the repo stays light -
a normal browser screenshot (not a huge 4K capture) is plenty.
